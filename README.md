# AniRetake

アニメ制作のリテイク指示カードを作成する単一HTMLツールです。
カットごとのリテイク内容と参考画像を、印刷・共有用のPNG画像として書き出せます。

> インストール・起動コマンド・公開手順は [COMMANDS.md](./COMMANDS.md) を見てください。  
> 版ごとの変更は [CHANGELOG.md](./CHANGELOG.md) です。

## やりたいこと → 見る場所

| やりたいこと | 見る場所 |
|---|---|
| 画面の操作・ショートカット | このファイル |
| 起動・公開・フォルダ構成 | [COMMANDS.md](./COMMANDS.md) |
| 更新内容の確認 | [CHANGELOG.md](./CHANGELOG.md) |

## 特徴

- カット別にリテイク内容・備考・参考画像を登録
- A5横カードのPNG書き出し（2480×1748px / 300DPI相当。A4縦に2面付け印刷向け）
- 参考画像が3枚以上ある場合は2枚目カードを自動生成（グリッド配置）
- 担当工程は環境設定（⚙アイコン）で追加・削除・並び替え・日付登録が可能
- 自動保存（ブラウザ内）・JSONバックアップ・テキスト出力
- インストール不要・オフライン動作。ファイル1つをブラウザで開くだけで使えます

## 使い方

1. `index.html` をブラウザで開く（または [GitHub Pages](https://akira-t5.github.io/AniRetake/)）
2. 共通情報（作品コード・話数・R回数・リテイク日）を入力
3. 「＋追加」でカットを追加し、カット番号・リテイク内容・参考画像を登録
4. 「PNG書き出し」で出力
5. ヘルプ（？）から免責・バージョン・ショートカットを確認できます

## ファイル名ルール

- 通常：`作品コード_話数_カット番号_R-01.png`
- 兼用あり：`作品コード_話数_カット番号-兼用番号_R-01.png`（兼用はハイフン・アンダーバーで複数連結可）
- 参考画像2枚目カード：末尾に `_2.png`

## ショートカット

| キー | 動作 |
|---|---|
| Ctrl/Cmd + Enter | カット追加 |
| Ctrl/Cmd + S | PNG書き出し |
| Ctrl/Cmd + D | カット複製 |
| Ctrl/Cmd + ↑ / ↓ | 前 / 次のカットへ移動 |

## 注意事項

- 本ソフトウェアは現状のまま提供され、動作や結果について保証しません
- 重要なデータは「JSON保存」でバックアップしてください
- 設定はブラウザの localStorage（キー：`retake.v7`）に保存されます。詳細は [COMMANDS.md](./COMMANDS.md)

## トラブル時の確認項目

- カット番号・リテイク内容が空だと PNG 書き出しできません
- 画像がプレビューに出ない場合は、別の画像形式で試してください
- データが消えたように見えるときは、別ブラウザ／`file://` と Pages の混在を疑ってください（保存場所が別になります）
- JSON読込に失敗したら、ファイルが AniRetake 用の JSON か確認してください

## 動作環境

- Windows / Mac 両対応
