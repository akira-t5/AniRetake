# AniRetake

アニメ制作のリテイク指示カードを作成する単一HTMLツールです。
カットごとのリテイク内容と参考画像を、印刷・共有用のPNG画像として書き出せます。

> 版ごとの変更は [CHANGELOG.md](./CHANGELOG.md) です。

## 特徴

- カット別にリテイク内容・修正内容・備考・参考画像を登録。カットごとに版（R-01, R-02…）を残せる
- 修正内容は本文とは別欄で、文字色（黒・赤・青）を版ごとに選べる。参考画像は1枚目だけをその下に出し、2枚目以降は別ページ（1ページ最大4枚）
- 画像はクリップボードから貼り付けできる（Ctrl+V）。サムネイルの「→」で他のカットへ移動・コピーできる。送り先は最新の版で、別の版にも変えられる
- 「状況をコピー」は、版番号・カット数・画像の枚数・保存状態だけをコピーする
- 各版に「作業済み」を付けられる。一覧のチェックは最新の版。一覧の上の「すべて／未了 N件／済 N件」の札で絞り込める（「未了」が以前の「作業済みを隠す」にあたる。もう一度押すと「すべて」に戻る）
- 「入力だけ見る」でプレビューを隠せる。優先度はカット番号の横で選ぶ
- 「同じカット番号をまとめて表示」で、同じ番号のカットを見出しごとにまとめて見られる。番号が1つだけのカットも一覧に残る
- 「新しい版を作る」で次のRが空で追加される。Rの数字を直すとその版の回数だけ変わる
- A5横カードのPNG書き出し（2480×1748px / 300DPI相当。A4縦に2面付け印刷向け）
- 参考画像が3枚以上ある場合は2枚目カードを自動生成（グリッド配置）
- 全PNG書き出しはZIPにまとめて出力。表計算ソフト用のTSV出力にも対応
- 画像はドラッグ&ドロップで登録（フォーム・プレビュー画面のどちらでも）。サムネイルの◀▶で順序変更、✕で外す（画像のクリックでは消えません）
- 画像1枚時は下寄せ配置、0枚時は画像エリアをメモ欄として使用（PNGに枠・表記を出しません）
- 担当工程は環境設定（⚙アイコン）で追加・削除・並び替え・日付登録が可能
- 自動保存（ブラウザ内）・JSONバックアップ・テキスト出力
- インストール不要・オフライン動作。ファイル1つをブラウザで開くだけで使えます

## 使い方

1. `index.html` をブラウザで開く（または [GitHub Pages](https://akira-t5.github.io/AniRetake/)）
2. 上部バーで作品コード・話数（必要なら新規カットの初期R）を入力
3. 「＋追加」でカットを追加し、カット番号・リテイク内容・修正内容・参考画像を登録
4. 「PNG書き出し」で出力。「全PNG」はZIPファイルにまとめて出力されます
5. 「出力・保存」メニューの「表用TSV出力」で A列:通し番号／B列:カット番号／C列:リテイク内容／D列:兼用カット番号 のファイルを出力できます（スプレッドシートへのコピー＆ペースト用。セル内の改行は引用符形式で保持されます）
6. ヘルプ（？）から免責・バージョン・ショートカットを確認できます

リテイク内容・修正内容・備考は、プレビューに収まる目安文字数を「あと ○○ / 上限」で表示します。超過しても入力はできますが、文字とカウントが赤くなり、カード上では見切れることがあります。

## ファイル名ルール

- 通常：`作品コード_話数_カット番号_R-01.png`
- 兼用あり：`作品コード_話数_カット番号-兼用番号_R-01.png`（兼用はハイフン・アンダーバーで複数連結可）
- 参考画像2枚目カード：末尾に `_2.png`
- 全PNG書き出し：`retake_png_作品コード_話数_R-01.zip`（上記PNGをすべて同梱）
- 表用TSV：`retake_list_作品コード_話数.tsv`（UTF-8 BOM付きタブ区切り）

## ショートカット

初期値は次のとおりです（環境設定の⚙から変更できます）。

| キー | 動作 |
|---|---|
| Ctrl/Cmd + Enter | カット追加 |
| Ctrl/Cmd + S | PNG書き出し |
| Ctrl/Cmd + D | カット複製 |
| Ctrl/Cmd + ↑ / ↓ | 前 / 次のカットへ移動 |

カット一覧をクリックしたあとは、↑↓で選択、Home／Endで先頭／末尾、Enterでリテイク内容の入力欄へ、Spaceで最新の版の済／未を切り替えられます。入力欄で Esc を押すと一覧へ戻ります（日本語の変換中は除く）。これらは固定で、環境設定では変えられません。

## 書き出しサイズ

環境設定から次を選べます（いずれも300DPI）。

| 用紙 | ピクセル |
|---|---|
| A5横（既定） | 2480×1748 |
| A4横 | 3508×2480 |

## 注意事項

- 本ソフトウェアは現状のまま提供され、動作や結果について保証しません
- 重要なデータは「JSON保存」でバックアップしてください（画像データと作業中のカット位置を含む全データが保存され、別環境で「JSON読込」すればそのまま作業を再開できます。読込時は「読み込み完了：Nカット・画像M枚」と表示されます。この表示で画像が0枚の場合、そのファイルには画像が保存されていません）
- テキスト・設定はブラウザの localStorage（キー：`retake.v8`）、画像は IndexedDB（ブラウザ内の大容量領域・数百MB目安）に1枚ずつ自動保存されます。v1.5以前のデータは初回起動時に自動で移行され、旧データ（`retake.v7`）はバックアップとして残ります。v1.6のデータは版管理用の形式へ更新され、更新前は `retake.v8.s2` に残ります
- 全PNG・テキスト・表用TSVは、各カットの最新版（Rが一番大きい版）を出します。画面の「PNG書き出し」は、いま表示している版です
- 画像は登録時に自動で最適化されます（長辺1920pxに縮小し、透過のない画像はJPEG化）。小さい画像や透過PNGは元のまま保持されます
- 上部バーの保存表示は「未保存の変更あり → 保存中… → 保存済み」と変わります。「保存済み」は実際に保存が完了したときだけ表示されます。入力中も最長約2秒ごとに保存されます
- 保存に失敗した場合は保存表示が赤くなります。その場合は「JSON保存」でバックアップしてください
- 同じデータを複数のタブで開いて編集すると、古い内容で上書きしないよう片方のタブの自動保存が止まり、画面上部に案内が出ます（「再読み込み」または「このタブの内容で上書き保存」を選べます）
- 保存データが読み込めない・新しいバージョンで保存されている場合は、データを上書きせずに自動保存を止めて案内を表示します
- 保存が終わる前にタブを閉じようとすると、ブラウザの確認が表示されます。画像の追加直後にすぐ閉じた場合など、その画像が保存されていないことがあります（次回起動時に案内が出ます）
- 上部バーにPNG書き出し・全PNGと「出力・保存」メニュー（テキスト出力・コピー・表用TSV・JSON保存／読込・状況をコピー・全リセット）があります。メニューは項目を選ぶか、外側をクリック・Escで閉じます
- プレビューをクリック（または「拡大」）すると画面いっぱいに表示します。もう一度クリックか Esc で戻ります。拡大中も Ctrl/Cmd+↑↓ で前後のカットを見られます
- 画面幅が狭いとき（約1180px以下）は、カット一覧を左に残したまま、カット名の横の「入力」「プレビュー」で表示を切り替えます（「入力だけ見る」の代わり）

## トラブル時の確認項目

- カット番号・リテイク内容が空だと PNG 書き出しできません
- 画像がプレビューに出ない場合は、別の画像形式で試してください
- データが消えたように見えるときは、別ブラウザ／`file://` と Pages の混在を疑ってください（保存場所が別になります）
- JSON読込に失敗したら、ファイルが AniRetake 用の JSON か確認してください
- 画像登録の直後に保存しても、画像の読み込み完了を待ってから保存されます
- HEIC形式の画像はChrome/Edgeでは表示できません（登録時に警告が出ます）。JPEG/PNGに変換するか、MacのSafariで開いてください

- 最新の Chrome / Edge / Safari
- Windows / Mac 両対応
