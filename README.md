# AniRetake

アニメ制作のリテイク指示カードを作成する単一HTMLツールです。
カットごとのリテイク内容と参考画像を、印刷・共有用のPNG画像として書き出せます。

> 版ごとの変更は [CHANGELOG.md](./CHANGELOG.md) です。

## 特徴

- カット別にリテイク内容・備考・参考画像を登録
- A5横カードのPNG書き出し（2480×1748px / 300DPI相当。A4縦に2面付け印刷向け）
- 参考画像が3枚以上ある場合は2枚目カードを自動生成（グリッド配置）
- 全PNG書き出しはZIPにまとめて出力。表計算ソフト用のTSV出力にも対応
- 画像はドラッグ&ドロップで登録（フォーム・プレビュー画面のどちらでも）。サムネイルの◀▶で順序変更
- 画像1枚時は下寄せ配置、0枚時は画像エリアをメモ欄として使用（PNGに枠・表記を出しません）
- 担当工程は環境設定（⚙アイコン）で追加・削除・並び替え・日付登録が可能
- 自動保存（ブラウザ内）・JSONバックアップ・テキスト出力
- インストール不要・オフライン動作。ファイル1つをブラウザで開くだけで使えます

## 使い方

1. `index.html` をブラウザで開く（または [GitHub Pages](https://akira-t5.github.io/AniRetake/)）
2. 共通情報（作品コード・話数・R回数・リテイク日）を入力
3. 「＋追加」でカットを追加し、カット番号・リテイク内容　修正指示・参考画像を登録
4. 「PNG書き出し」で出力。「全PNG」はZIPファイルにまとめて出力されます
5. 「表用TSV」で A列:通し番号／B列:カット番号／C列:リテイク内容／D列:兼用カット番号 のファイルを出力できます（スプレッドシートへのコピー＆ペースト用。セル内の改行は空白に置き換わります）
6. ヘルプ（？）から免責・バージョン・ショートカットを確認できます

リテイク内容　修正指示と備考は、プレビューに収まる目安文字数を「あと ○○ / 上限」で表示します。超過しても入力はできますが、文字とカウントが赤くなり、カード上では見切れることがあります。

## ファイル名ルール

- 通常：`作品コード_話数_カット番号_R-01.png`
- 兼用あり：`作品コード_話数_カット番号-兼用番号_R-01.png`（兼用はハイフン・アンダーバーで複数連結可）
- 参考画像2枚目カード：末尾に `_2.png`
- 全PNG書き出し：`retake_png_作品コード_話数_R-01.zip`（上記PNGをすべて同梱）
- 表用TSV：`retake_list_作品コード_話数.tsv`（UTF-8 BOM付きタブ区切り）

## ショートカット

初期値は次のとおりです（環境設定の⚙から変更できます）。

| キー | 動作 |
|---|---|
| Ctrl/Cmd + Enter | カット追加 |
| Ctrl/Cmd + S | PNG書き出し |
| Ctrl/Cmd + D | カット複製 |
| Ctrl/Cmd + ↑ / ↓ | 前 / 次のカットへ移動 |

## 書き出しサイズ

環境設定から次を選べます（いずれも300DPI）。

| 用紙 | ピクセル |
|---|---|
| A5横（既定） | 2480×1748 |
| A4横 | 3508×2480 |

## 注意事項

- 本ソフトウェアは現状のまま提供され、動作や結果について保証しません
- 重要なデータは「JSON保存」でバックアップしてください
- 設定はブラウザの localStorage（キー：`retake.v7`）に保存されます
- 画像はブラウザ内に保存されるため、大きい画像を多数登録すると保存容量（目安5MB前後）を超えることがあります。保存に失敗した場合はサイドバーの保存表示が赤くなります。その場合は画像を減らすか「JSON保存」でバックアップしてください
- サイドバー上部（アプリ名・出力・保存）は固定表示です。「出力・保存」の見出しをクリックすると開閉できます

## トラブル時の確認項目

- カット番号・リテイク内容　修正指示が空だと PNG 書き出しできません
- 画像がプレビューに出ない場合は、別の画像形式で試してください
- データが消えたように見えるときは、別ブラウザ／`file://` と Pages の混在を疑ってください（保存場所が別になります）
- JSON読込に失敗したら、ファイルが AniRetake 用の JSON か確認してください
