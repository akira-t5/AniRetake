# シート通信の確認（開発用）

スプレッドシート共有（v2.1.0 予定）を作る前に、AniRetake から Google スプレッドシートへ通信できるかを確かめるためのセットです。公開版には含まれません（このフォルダは `feature/sheet-sync` ブランチだけにあります）。Windows・Mac どちらでも同じ手順です。

## 1. テスト用のシートを用意する（5分）

1. Google ドライブで新しいスプレッドシートを作る（名前は何でもよい。例：`AniRetake通信テスト`）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っている `function myFunction() {}` を全部消し、`probe.gs` の中身を全部貼り付ける
4. 1行目近くの `const KEY = "test-aikotoba";` の文字を好きな合言葉に変えてもよい（変えたら下の手順でも同じものを使う）
5. 💾（保存）を押す
6. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 「デプロイ」を押す。初回は「アクセスを承認」→ 自分のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトを自分のシートで動かすための確認なので、この警告は正常です
8. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーする

## 2. 通信を試す（2通り）

**A. ファイルを直接開く場合**：`probe.html` をダウンロードしてダブルクリックで開く（Chrome / Edge / Safari）

**B. 公開版と同じ https で開く場合**：あとで別途用意します（まず A だけで構いません）

1. URL 欄にコピーした URL を貼る
2. 合言葉を確認する
3. 「① 受け取りテスト」を押す →「成功」と出るか
4. 「② 書き込みテスト」を押す →「成功」と出て、シートに「probe」タブができ、1行増えるか

## 3. 結果を知らせる

次の3つを開発者（Claude）に伝えてください。

- 使ったブラウザ（例：Windows の Chrome、Mac の Safari）
- ①と②それぞれの「成功／失敗」と、結果欄の文字（数字の ms も）
- シートに行が増えたか

## 終わったら

確認が済んだら、Apps Script の「デプロイ」→「デプロイを管理」→ アーカイブ（ゴミ箱）で止められます。テスト用シートは消して構いません。
